## 2. 人工流程验收

> 前置：`AUTH_ENABLED=true`（后端）+ `AUTH_REQUIRED=true`（前端 App.jsx）。

```text
1.  打开系统，未登录访问任意页面自动跳转 /login
2.  注册新用户
3.  登录成功进入数据管理页
4.  上传 CSV
5.  查看字段画像
6.  执行清洗
7.  进入智能分析
8.  简单模式生成报表
9.  高级（多智能体）模式生成报表（无 LLM Key 时自动降级，仍应出报表）
10. 查看报表图表、结论、数据表、决策记录
11. 刷新页面后报表仍可从后端历史读取
12. 删除报表后刷新不再出现
13. 用户 A 退出，用户 B 登录，看不到 A 的数据和报表
```

API 层等价验收（真实 HTTP）：

```powershell
python -m uvicorn api.main:app --port 8000   # AUTH_ENABLED=true
# 依次验证：注册A/B → 上传 → 画像 → 清洗 → 简单/多智能体生成报表
#   → 历史列表 → 详情 → 删除 → B 访问 A 的 dataset/report 均 404
```

## 3. 安全验收

```text
1. 不带 token 访问 /datasets/ 返回 401
2. 伪造 token 访问返回 401
3. 用户 B 访问用户 A 的 dataset_id 返回 404（而非 403/200）
4. 用户 B 访问用户 A 的 report_id 返回 404
5. 前端请求里没有 X-LLM-API-Key（api.js 只发 X-LLM-Provider / X-LLM-Model）
6. 前端请求里没有 X-LLM-Base-URL
7. 后端日志里没有 API key（llm客户端.py 仅记录状态码）
```

以上 1–4 已在集成测试覆盖（`tests/test_api_integration.py`），5–7 通过代码审查 + 抓包/日志抽查确认。
