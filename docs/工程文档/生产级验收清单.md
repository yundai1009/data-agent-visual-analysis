## 3. 安全验收

```text
1. 不带 token 访问 /datasets/ 返回 401
2. 伪造 token 访问返回 401
3. 用户 B 访问用户 A 的 dataset_id 返回 404（而非 403/200）
4. 用户 B 访问用户 A 的 report_id 返回 404
5. 前端请求里没有 X-LLM-API-Key（api.js 只发 X-LLM-Provider / X-LLM-Model）
6. 前端请求里没有 X-LLM-Base-URL
7. 后端日志里没有 API key（llm_client.py 仅记录状态码）
8. `AUTH_ENABLED=false` 时绑定 `0.0.0.0` 启动即退出（回环强制，`tests/backend/test_startup_safety.py`）
9. 免认证模式下改密/改名/注销/导出返回 400"演示模式不支持账号操作"（`tests/backend/test_demo_mode_guard.py`）
10. 向量记忆库指纹与当前 embedding 配置不一致时启动即退出（`tests/backend/test_阶段61_记忆库一致性.py`）
```
