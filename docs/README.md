**新读者从这里开始**，每篇一句话告诉你该不该读。

```
docs/
├── README.md            ← 你在这里
├── 使用指南/             ← 用户向：怎么用

├── 计划与复盘/           ← 计划与落地状态

```

## 维护约定

1. **新文档**放进对应子目录；不确定的放 `工程文档/` 并在这里登记一行。
2. **开发日志**：每次实质性改动在 `开发日志/项目开发日志.md` 追加新阶段，并更新顶部导航表。
3. **本地保留、不推送**的文档（如 `用户使用指南.md`、`从零理解项目.md`）在 `.gitignore` 中
   声明，不要 `git add`。
