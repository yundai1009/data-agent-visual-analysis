# 更改计划：自然语言自动选字段（让"输入一句话出图"真正成立）

## 背景与问题

当前"自然语言 → 图表"链路只解决了**选图表类型**，字段选择仍靠简单规则：

```text
用户输入"生成词云图"
  → 规则识别图表类型 = 词云图 ✓
  → 字段选择 = "分类字段[0]"（第一个分类字段）✗
     · 若第一个分类字段是"地区"（短枚举）→ 分词切出地区名，效果差
     · 若是数值字段（单列数据）→ 直接 400"未提取到有效词"
  → 用户被迫切到高级模式手动选字段 ← 与"自然语言生成"的初衷矛盾
```

**核心问题：系统不知道哪些字段是"文本字段"（适合分词）、哪些是"短枚举"、哪些是"数值"——所以规则无法做出语义正确的选择。**

## 目标

**所有 18 种图表**：输入自然语言 → 图表类型 + 字段 + 聚合方式**全部自动选对**，零手动操作；选不了时给"为什么 + 建议换什么"，而不是让用户自己摸索。**一次性实施完成，不分阶段。**

## 全图表字段自动选择矩阵

| 图表 | 需要的字段 | 自然语言自动选择 |
|---|---|---|
| 柱状图/折线图/面积图/直方图 | x=分类或日期, y=数值 | x=分类[0] 或 日期[0]，y=数值[0] 或记录数 |
| 饼图/环形图 | x=分类, y=数值/计数 | x=分类[0]，y=数值[0] 或记录数 |
| 散点图 | x=数值, y=数值 | x=数值[0]，y=数值[1] 或 数值[0] |
| 箱线图/K线图 | x=分类或日期, y=数值（x≠y） | x=分类[0] 或 日期[0]，y=数值[0]；x==y 时自动换 |
| 热力图/堆积柱状图 | x=分类, 分组=分类, y=数值 | x=分类[0]，分组=分类[1]，y=数值[0] 或记录数 |
| 雷达图 | x=分类, y=多个数值 | x=分类[0]，y=数值[:3]（至少 2 个） |
| 漏斗图/瀑布图 | x=分类, y=数值 | x=分类[0]，y=数值[0] 或记录数 |
| 桑基图/旭日图 | 两级分类 + 值 | 源/内层=分类[0]，目标/外层=分类[1] |
| 词云图 | x=文本字段 | x=文本字段[0]；无则分类里最长的；再无则提示换图 |
| 表格/自动推荐 | 任意 | 保持 |

## 一次性实施清单

### A. 数据画像：识别"文本字段"（根因层）

**文件**：`后端_核心/数据画像.py`

- `_字段分组()` 在分类字段内细分**文本字段**：该列**平均字符长度 > 6** 且 **唯一值占比 > 30%**
- `生成数据画像()` 输出新增 `"文本字段": List[str]`（随数据集持久化、随画像返回前端）

### B. 后端统一字段选择器（核心）

**文件**：`后端_核心/上传报表生成器.py` 新增 `自动选字段(画像, 图表类型)`：

- 按上表矩阵返回 `{x轴, y轴列表, 分组字段, 聚合方式}`，字段不足时自动降级（散点缺第二个数值→用第一个；箱线 x==y → x 换日期/分类）
- **接入点**：
  1. `_受控语句配置` 命中关键词 → 图表类型 + `自动选字段()` 的字段组合
  2. `_意图驱动配置`（未命中规则时的自动推荐）→ 同样用选择器
  3. `_生成词云数据` / `_生成箱线图数据` / `_生成K线数据` 等函数内部：字段不适配时**自动探测重选**（最后兜底，不抛错）
- 选不了时的报错信息统一带建议（"此数据集无文本字段，建议改用柱状图/饼图"）

### C. 前端：选图即自动换字段

**文件**：`frontend/src/pages/Analysis.jsx`

- 选中图表类型时（`setChartType` 包装）自动重选字段：
  - 词云 → X 轴切文本字段
  - 散点 → X/Y 切数值字段
  - 箱线/K线 → 校验 x≠y
  - 热力图/堆积/桑基/旭日 → 分组自动给分类字段
- `validateChartFields` 补全前置校验；X 轴下拉文本字段加 📝 标记

### D. LLM 意图链路一致

**文件**：`后端_核心/agent/编排器.py`

- LLM 输出的字段校验不过时，回退到 `自动选字段()`（规则与 LLM 行为一致）

### E. 测试

**文件**：`tests/test_api_integration.py` + `tests/test_数据画像.py`

| 用例 | 断言 |
|---|---|
| 文本字段识别 | 含"评论"列 → `画像.文本字段 == ["评论"]` |
| 自然语言"生成词云图" | 自动选"评论"，200 + wordcloud |
| 18 图表 × 自然语言关键词 | 全部 200，字段自动正确（矩阵回归） |
| 词云 + 无文本字段 | 400 且 message 带换图建议 |
| 词云 + 单列数值 | 400 建议（非 500） |

| 箱线/K线 x==y | 自动换字段 200，或 400 带建议 |
| LLM mock 输出错误字段 | 回退规则选择器 |
