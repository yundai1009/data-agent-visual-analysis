# Real MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the mock loop into a demonstrable real MVP: natural language question -> OpenAI-compatible NL2SQL -> MySQL read-only query -> real table/chart/conclusion in Streamlit.

**Architecture:** Keep the existing FastAPI `/tasks` API and Streamlit task page. Add a small backend service layer under `后端_核心/` for environment config, MySQL schema/query execution, SQL safety checks, OpenAI-compatible LLM calls, and result assembly. `api/routes/tasks.py` remains the orchestration boundary and stores demo task records in memory.

**Tech Stack:** Python 3.11, FastAPI, Streamlit, requests, pandas, MySQL via `pymysql`.

## Global Constraints

- Use environment variables for all MySQL and LLM credentials; never hard-code secrets.
- Only allow read-only SQL for MVP: one `SELECT`/`WITH` statement, no DDL/DML, no multiple statements.
- Limit returned rows to a configurable maximum, default `200`.
- Do not add Redis, Chroma, LangGraph, WebSocket, or multi-worker state sharing in this iteration.
- Preserve existing Chinese API fields and Streamlit page names.

## Manual Verification

Install dependencies:

```powershell
pip install pymysql requests fastapi uvicorn streamlit pandas plotly streamlit-option-menu streamlit-ace
```

Set environment variables in PowerShell:

```powershell
$env:MYSQL_HOST="127.0.0.1"
$env:MYSQL_PORT="3306"
$env:MYSQL_USER="your_mysql_user"
$env:MYSQL_PASSWORD="your_mysql_password"
$env:MYSQL_DATABASE="your_database_name"
$env:LLM_BASE_URL="https://api.openai.com/v1"
$env:LLM_API_KEY="your_llm_api_key"
$env:LLM_MODEL="gpt-4o-mini"
$env:AGENT_API_BASE_URL="http://127.0.0.1:8000"
$env:AGENT_API_TIMEOUT="120"
```

Start backend:

```powershell
python api\main.py
```

Start frontend in another PowerShell:

```powershell
streamlit run 前端_streamlit\主入口.py
```

Demo prompt examples:

```text
统计最近 30 天每天的订单量和销售额
按渠道统计最近 7 天 GMV 排名前 10
查询本月各城市订单数和平均客单价
```

Expected behavior:

1. Streamlit submits a natural language question.
2. FastAPI reads MySQL schema.
3. LLM returns one MySQL read-only SQL statement.
4. Backend safety check blocks non-read-only SQL.
5. Backend executes query against MySQL.
6. Streamlit displays SQL, real data table, chart, and conclusion.

## Known MVP Limitations

- Task records are still stored in memory and disappear after backend restart.
- Backend task execution is synchronous; long LLM/SQL calls block the request.
- No Redis, Chroma, LangGraph, WebSocket, or multi-worker shared state yet.
- SQL safety check is conservative but not a full SQL parser.
- LLM token/cost fields currently return `0` because provider usage formats differ.
