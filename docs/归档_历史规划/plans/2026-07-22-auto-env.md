# Auto .env Loading Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let backend and frontend automatically read project-root `.env` values for MySQL, LLM, and API settings.

**Architecture:** Use `python-dotenv` in `config/settings.py` to load `D:\python\agent\自助式数据分析Agent平台\.env` at import time with `override=False`, so real system environment variables still win. Import `EnvConfig` in the Streamlit API client to trigger the same load path before reading `AGENT_API_BASE_URL`.

**Tech Stack:** Python 3.11, python-dotenv.

## Global Constraints

- `.env` may contain secrets and must not be committed.
- `.env.example` stays safe and contains placeholders only.
- System environment variables override `.env` values.

---

## Implemented Changes

- Modified: `config/settings.py`
  - Imports `load_dotenv` from `dotenv`.
  - Computes project root using `Path(__file__).resolve().parents[1]`.
  - Loads `.env` from project root with `override=False`.
- Modified: `前端_streamlit/服务/api客户端.py`
  - Imports `EnvConfig` so `.env` is loaded before reading `AGENT_API_BASE_URL` and `AGENT_API_TIMEOUT`.
- Created: `.gitignore`
  - Ignores `.env`, Python caches, and `.streamlit/secrets.toml`.
- Modified: `.env.example`
  - Adds `AGENT_API_TIMEOUT=120`.
  - Adds copy/use warning comments.

## Required Dependency

Install:

```powershell
pip install python-dotenv
```

Or install together with the other app dependencies:

```powershell
pip install python-dotenv pymysql requests fastapi uvicorn streamlit pandas plotly streamlit-option-menu streamlit-ace
```

## How To Use

Copy example config:

```powershell
cd D:\python\agent\自助式数据分析Agent平台
Copy-Item .env.example .env
```

Edit `.env` and replace placeholder values:

```env
MYSQL_USER=your_mysql_user
MYSQL_PASSWORD=your_mysql_password
MYSQL_DATABASE=your_database_name
LLM_API_KEY=your_llm_api_key
```

Start backend:

```powershell
python api\main.py
```

Start frontend:

```powershell
streamlit run 前端_streamlit\主入口.py
```
