## 一、快速启动

### 前置条件

- Python 3.11+
- Node.js 18+
- （可选）DeepSeek / OpenAI API Key

### 1. 安装后端依赖

```powershell
cd D:\python\agent\自助式数据分析Agent平台
pip install -r requirements.txt
```

### 2. 配置 LLM（可选但推荐）

```powershell
copy .env.example .env
```

编辑 `.env`，填入你的 API Key：

```ini
# DeepSeek 示例
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_API_KEY=sk-your-deepseek-key-here
LLM_MODEL=deepseek-chat

# OpenAI 示例（注释掉上面的，取消注释下面）
# LLM_BASE_URL=https://api.openai.com/v1
# LLM_API_KEY=sk-your-openai-key-here
# LLM_MODEL=gpt-4o-mini
```

> 不配 LLM key 也能用，系统会自动降级到关键词匹配兜底。

### 3. 安装前端依赖

```powershell
cd D:\python\agent\自助式数据分析Agent平台\frontend
npm install
```

### 4. 启动

#### 方式 A：一键启动（推荐）

```powershell
cd D:\python\agent\自助式数据分析Agent平台
.\启动.ps1
```

#### 方式 B：分两个终端启动

**终端 1 — 后端：**

```powershell
cd D:\python\agent\自助式数据分析Agent平台
python -m uvicorn api.main:app --reload --port 8000
```

**终端 2 — 前端：**

```powershell
cd D:\python\agent\自助式数据分析Agent平台\frontend
npm run dev
```

浏览器打开 `http://localhost:5173` 即可使用。

## 三、数据管理

### 上传文件

1. 进入「数据管理」页面
2. 拖拽 CSV / Excel 文件到上传区域，或点击上传区域选择文件
3. 等待上传进度条完成
4. 上传成功后，系统自动生成数据画像

### 数据概览

上传后显示 4 个卡片：

| 卡片 | 说明 |
|------|------|
| **总行数** | 数据集的行数，附带数据量评估 |
| **字段数** | 字段总数 + 日期/分类/数值分布 |
| **数据质量评级** | A/B/C 三档 + 等级说明 |
| **缺失值数量** | 点击可查看每个字段的缺失详情 |

### 字段列表

- 支持**搜索**字段名
- 支持按**类型筛选**（全部/日期/分类/数值）
- 每行显示字段名 + 类型标签 + 字段建议
- 鼠标悬停出现「预览」和「加入分析」按钮
- **预览**：弹出字段详情弹窗（类型、空值数量、字段建议）
- **加入分析**：自动跳转到智能分析页，该字段作为焦点

### 快捷操作

| 操作 | 说明 |
|------|------|
| **基于此数据集新建分析** | 跳转到智能分析页，数据集上下文自动带入 |
| **一键基础清洗** | 自动执行去重 + 填充缺失值 + 删除空行，完成后弹出清洗结果摘要 |
| **查看报表** | 跳转到报表查看页 |

### 导入示例数据

点击页面右上角的「导入示例数据」按钮，系统自动加载内置的销售数据集（30 行，6 个字段），无需自己找文件。

## 四、智能分析

### 基本流程

1. 确保已上传数据集（或在数据管理页点击「加入分析」/「新建分析」自动带入）
2. 在输入框中用自然语言描述分析需求
3. （可选）点击快速模板一键填充
4. 选择图表类型
5. 配置字段（X 轴、Y 轴、分组字段、聚合方式）
6. 选择 Agent 模式和模型
7. 点击「开始分析」

### 自然语言输入

示例需求：

```
按【地区】统计【销售额】占比
按【月份】查看【销售额】趋势变化
统计各【岗位类型】的【平均薪资】
对比各【产品线】的【利润率】
```

使用 `【字段名】` 格式标记字段，系统会自动识别。

### 快速模板

提供 4 个常用模板，点击自动填入输入框：

- 📊 占比分布
- 📈 趋势变化
- 📊 分组对比
- 🔀 交叉分析

### 图表类型

| 图表 | 适用场景 |
|------|---------|
| 柱状图 | 分组对比、分类比较 |
| 折线图 | 时间趋势、连续变化 |
| 饼图 | 占比分布、构成分析 |
| 散点图 | 相关性分析、数值关系 |
| 热力图 | 交叉分布、矩阵关系 |
| 表格 | 精确数值查看 |
| 堆积图 | 分量与总量的关系 |

### 字段配置

| 参数 | 说明 |
|------|------|
| X 轴 | 分类/日期字段，作为横轴 |
| Y 轴 | 数值字段，作为指标 |
| 分组字段 | 可选，用于颜色区分 |
| 聚合方式 | 求和 / 平均值 / 计数 / 最大值 / 最小值 |

字段下拉选项从上传数据的数据画像中动态加载。

## 六、Agent 模式说明

系统提供两种 Agent 工作模式，在智能分析页面切换。

### 单 Agent 模式（默认）

**工作流程：**

```
用户需求
  │
  ▼
┌─────────────────────────────────┐
│         1 个 Agent               │
│  ┌──── 第1轮：获取数据画像 ────┐ │
│  └──── 第2轮：聚合分析 ──────┘ │
│  └──── 第3轮：推荐图表+结论 ──┘ │
└─────────────────────────────────┘
  │
  ▼
报表
```

**特点：**
- 3 轮连续推理，每轮 LLM 看到上一轮结果
- Tool executor 实际执行聚合、推荐
- 任何一轮失败自动降级到关键词匹配

**适用场景：** 大多数日常分析任务

### 多智能体模式

**工作流程：**

```
用户需求
  │
  ▼
┌─────────────────────────────────────────┐
│         Supervisor Agent                │
│  理解需求 → 依次调度团队成员              │
├─────────────────────────────────────────┤
│  ┌── 数据分析师 Agent ──────────────┐  │
│  │  1. 调「获取数据画像」查看数据    │  │
│  │  2. 调「聚合分析」计算数据        │  │
│  └────────────────────────────────┘  │
│  ┌── 图表设计师 Agent ──────────────┐  │
│  │  1. 调「推荐图表」选图表类型      │  │
│  │  2. 调「生成结论」写分析结论      │  │
│  └────────────────────────────────┘  │
│  ┌── 质量审查员 Agent ──────────────┐  │
│  │  检查结果合理性                  │  │
│  │  不通过 → 打回重做               │  │
│  └────────────────────────────────┘  │
└─────────────────────────────────────────┘
  │
  ▼
报表
```

**特点：**
- 每个 Agent 有独立的 system prompt，专注自身角色
- 数据分析师看不到图表逻辑，图表设计师不碰数据
- 质量审查员可以打回重做，形成反馈闭环
- 多智能体失败 → 自动降级到单 Agent

**适用场景：** 复杂分析、对结果准确性要求高的任务

### 如何选择

| 场景 | 推荐模式 |
|------|---------|
| 快速看数据分布 | 单 Agent |
| 标准报表生成 | 单 Agent |
| 需要质量审查的分析 | 多智能体 |
| 不确定字段选择是否正确 | 多智能体 |
| 演示/教学场景 | 多智能体（展示 Agent 分工流程） |

## 七、模型切换说明

### 在分析页面切换

智能分析页面的「模型选择」下拉支持：

| 模型 | 说明 |
|------|------|
| 系统默认 | 使用 `.env` 中配置的 `LLM_MODEL` |
| GPT-4o Mini | OpenAI 快速模型 |
| GPT-4o | OpenAI 最强模型 |
| DeepSeek Chat | DeepSeek 标准模型 |
| DeepSeek V4 | DeepSeek 最新模型 |

> 注意：切换模型需要该模型对应 API Key 已配置到 `.env` 的 `LLM_API_KEY` 中。
>
> 如果该模型不兼容当前 base_url（例如选择 GPT 但 base_url 是 DeepSeek），会调用失败并降级到关键词匹配。

### 永久切换（改 .env）

```ini
# 改这里就行，代码零改动
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-chat
```

支持：DeepSeek / OpenAI / 硅基流动 / 任意 OpenAI 兼容 API

## 九、常见问题

### Q：没有 LLM key 能用吗？

可以。系统自动降级到关键词匹配，准确率约 10%-70%（图表类型 70%，Y 轴 35%）。

### Q：多智能体模式比单 Agent 慢多少？

多智能体模式需调用 LLM 4-6 次（每个 Agent 1-2 轮），单 Agent 只需 3 轮。预期延迟增加约 50-100%。

### Q：切换模型后没生效？

模型选择仅对当前请求生效。如果希望永久切换，请修改 `.env` 中的 `LLM_MODEL`。

### Q：上传文件大小有限制吗？

单文件不超过 50MB。支持 .csv、.xlsx、.xls 格式。

### Q：数据存在哪里？

上传文件存储在 `data/uploads/`，数据画像和分析结果存储在 SQLite 文件 `data/daa.db`，Agent 长期记忆存储在 `data/chroma_db/`。

### Q：如何停止运行？

```powershell
.\启动.ps1 -Stop
```

或手动关闭两个终端窗口。

### Q：端口被占用？

```powershell
.\启动.ps1 -BackendPort 8001 -FrontendPort 8502
```
