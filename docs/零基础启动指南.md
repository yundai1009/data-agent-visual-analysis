# 零基础启动指南（图形化启动器）

> 适合完全不懂代码的用户。只需要 **Python**（装过一次就好），不需要 Node、不需要敲任何命令。

## 只需要 3 步

### 第 1 步：安装 Python（只做一次）

1. 打开浏览器，访问 <https://www.python.org/downloads/>
2. 点黄色的 **Download Python 3.11**（或更新的 3.x 版本）
3. 双击下载的文件，安装时**务必勾选**左下角的 `Add python.exe to PATH`
4. 一路点 Next 装完

### 第 2 步：安装依赖（只做一次）

双击运行项目里的 **`安装依赖.bat`**（没有就打开 PowerShell，执行一次下面命令）：

```powershell
pip install -r requirements.txt
```

### 第 3 步：双击启动器

**方式一（推荐）：双击桌面图标**
桌面上已有一个带 logo 图标的 **「数据分析 Agent 平台」** 快捷方式，双击它：
- 弹出启动器窗口（带 logo）→ **进度条滚动**表示正在启动 → 进度条完成后浏览器自动打开**登录界面**
- 直接注册/登录即可使用

**方式二：双击项目里的 `launch_gui.pyw`**

双击项目根目录的 **`launch_gui.pyw`**，出现图形窗口：

```
┌────────────────────────────────────────────┐
│  📊 数据分析 Agent 平台                     │
│  选择一个模式启动，浏览器会自动打开          │
│  [🚀 正式模式启动] [🎁 演示模式启动] [⏹ 停止] │
│  状态：运行中  访问地址：http://127.0.0.1:8000 │
└────────────────────────────────────────────┘
```

| 按钮 | 适合谁 | 说明 |
|------|--------|------|
| 🚀 正式模式 | 自己长期使用 | 需要注册/登录账号，数据按用户隔离 |
| 🎁 演示模式 | 给别人演示、第一次体验 | **免登录**，打开浏览器自动加载示例数据（30 行销售数据），直接点"基于此数据集新建分析"就能出报表 |

点完按钮，浏览器会自动打开 `http://127.0.0.1:8000`，看到页面就成功了。

## 常见问题

**Q：点启动后提示"端口 8000 已被占用"？**
A：说明已经有一个实例在运行，或别的软件占用了 8000。打开任务管理器找 Python 进程结束，或关掉占用 8000 的程序再试。

**Q：演示模式里想清空数据重新来？**
A：演示模式的数据存在独立的 `data/demo.db`，删掉这个文件再启动就是全新状态。

**Q：正式模式注册的账号忘了密码？**
A：目前没有找回功能，重新注册一个新账号即可（不同账号数据互相隔离）。

**Q：生成报表时提示"分析失败"？**
A：LLM 未配置 Key 时会自动降级为规则分析，报表仍会生成。想让 AI 更聪明，在项目根目录 `.env` 文件里填 `LLM_API_KEY=你的key`（找懂的人帮忙）。

## 运行原理（一句话）

双击启动器 → 图形界面 → 点按钮 → 后端服务启动（Python 进程）→ 浏览器打开页面 → 页面和接口都由这一个进程提供，所以**不需要 Node**。
