# 后端打包说明（PyInstaller）

## 产物布局
npm run build:backend 产出：
- electron/dist-backend/daa-backend.exe  —— 入口
- electron/dist-backend/_internal/       —— 依赖（pandas/chromadb/uvicorn 等）

## 运行方式
Electron 主进程 spawn 该 exe，env 注入：
- AUTH_ENABLED=false（免登录 + 回环自锁）
- HOST=127.0.0.1, API_PORT/PORT=空闲端口
- DAA_SQLITE_PATH=%APPDATA%\数据分析Agent\data\daa.db
- cwd = %APPDATA%\数据分析Agent\data（parquet 相对路径落此）

## 新增 Python 依赖后
若后端新增了动态导入的库，需同步补 hiddenimports（daa-backend.spec），
否则打包产物会因缺失模块启动即崩。验证方式：见 Task 2 Step 5 冒烟。
