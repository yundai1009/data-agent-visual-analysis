# 安装与使用说明（桌面版）

## 安装包
1. 双击 `自助式数据分析Agent平台-0.1.0-x64.exe`（NSIS 安装器，可自选目录，无需管理员）
2. 安装完成自动创建桌面/开始菜单快捷方式「自助式数据分析Agent平台」
3. 双击快捷方式启动，独立窗口打开，无需浏览器/无需命令行

## 免安装版
解压 `自助式数据分析Agent平台-0.1.0-x64-portable.exe`（或 release/win-unpacked 目录）后双击 exe 直接运行。

## 数据位置
所有数据存 `%APPDATA%\数据分析Agent\`（daa.db / parquet / 上传文件 / 日志）。
换机迁移：整目录拷贝即可。卸载安装包**不会**删除 %APPDATA% 数据（用户数据保留）。

## 与网页版账号同步（MySQL 模式）
默认开箱即用：本地 SQLite + 演示模式（免登录）。
若要与网页版共用同一套账号/数据集，配置 `%APPDATA%\数据分析Agent\settings.json`：

```json
{
  "数据库": {
    "模式": "mysql",
    "主机": "127.0.0.1",
    "端口": 3306,
    "用户": "daa_app",
    "密码": "你的MySQL密码",
    "库名": "daa"
  },
  "认证模式": "real",
  "JWT密钥": "任意的强随机串（64位十六进制）",
  "预置管理员口令": "非默认的预置口令"
}
```

- 需先保证 MySQL 服务已启动，且 `daa` 库内数据已就绪（可用主仓库 `scripts/migrate_sqlite_to_mysql.py` 从 sqlite 迁移）。
- 改完配置重启应用即可。JSON 若由记事本/PowerShell 保存带 BOM 也能正常解析（已容错）。
- 密码以明文存本机配置文件，请保护好 `%APPDATA%\数据分析Agent\` 目录。

## 首次运行的 SmartScreen 提示
未签名版本会出现「Windows 已保护你的电脑」——点击「更多信息」→「仍要运行」。
正式签名证书到位后（二期）此提示消除。

## 检查更新
窗口内「检查更新」拉取 GitHub Releases 最新版（一期为跳转下载页）。
